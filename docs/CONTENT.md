# Content to add to the Google Sheet

Writing these does more for search ranking than any code change.

## 1. Project descriptions → `projects` tab

`projects-tab-draft.csv` lists every project with the facts visible in the work
already filled in. Replace each `[...]` and paste the rows into the `projects`
tab (columns `project` and `description`; the `project` values must match the
media tab exactly).

Aim for 2–3 sentences per project:

1. **What it is**: client, brand, format, year.
2. **Your role**: e.g. "Creative direction and art direction at Wieden+Kennedy".
3. **What it achieved**: an award, a result, or what made the idea work.

These become the description under your link on Google, the link preview on
LinkedIn/WhatsApp, and what ChatGPT/Claude/Perplexity say about the project.

## 2. Alt text → media tab, `alt` column

`alt-text-for-sheet.csv` has new alt text for the 26 still images that still
say "This image needs a description." Paste each into the row with the same
`id`.

The 21 **videos** still need one line each describing what happens in them;
the site currently shows "Video from the <project> project" for those.
